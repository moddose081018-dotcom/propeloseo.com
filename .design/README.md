# Homepage design directions

Working sources for the PropeloSEO homepage design canvas. Each `.dc.html` file is
one artboard; `canvas.json` positions them and holds the notes that explain each
direction's rationale and tradeoff.

| Artboard | Direction |
| --- | --- |
| `Main.dc.html` | A · Evidence-first — Trust Score terminal as the hero, dark fold |
| `MainMobile.dc.html` | A at 390px wide |
| `Editorial.dc.html` | B · Editorial ledger — serif, hairline rules, scan as a table |
| `SprintBoard.dc.html` | C · Sprint board — the 90-day board above the fold |
| `PriceForward.dc.html` | D · Price-forward — $97 as the argument |

All four reuse the tokens already in `index.html`: `#2563eb` action, `#0f172a` dark,
slate text, the Catppuccin terminal palette, and the 16/10/6px radii. Copy is taken
from the live page; no figures are invented.

These are exploration only — nothing here is wired into the published site.
