# LinkedIn Performance Log

Log post-by-post metrics here after each post. The linkedin-engine skill reads this to identify patterns and self-improve.

Format:
```
## YYYY-MM-DD — [topic slug]
- Format: document | text | multi-image | video | poll
- Hook used: [first line of the post]
- Impressions: [number]
- Likes: [number]
- Comments: [number]
- Reposts: [number]
- Profile visits: [number]
- Post link: [URL]
- Notes: [any qualitative observation — what comment themes emerged, who engaged, etc.]
```
